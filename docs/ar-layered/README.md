# 四组纹样六层 AR 拆解

每组纹样由同一幅 2×3 透明图集切为六张独立、同尺寸 PNG 纹样层。层名描述本次视觉拆分，不代表考古复原、原物构造或传统刺绣工艺分层。原图集及图层由 AI 根据用户提供且用户确认可用的参考图辅助重绘；不是对参考图进行像素级抠图。历史名称来自用户提供图片中的注记，未独立核实。

## 图层来源

- `sources/caisson-six-layer-atlas.png`：藻井外框、外饰、主瓣、间饰、中心放射纹、珠点。
- `sources/tuanshan-six-layer-atlas.png`：木色底盘、宝石边框、四瓣窗芯、蓝色团花、象牙白小花、中心花心。
- `sources/haitang-six-layer-atlas.png`：海棠底盘、深色框、青绿花瓣、蓝色内瓣、珊瑚色花芯、中心与角饰。
- `sources/pipa-six-layer-atlas.png`：团花底层、金色外框、青绿主瓣、深色内瓣、中心花饰、四角团花。

图集顺序为从后往前。所有部件使用同一方形画布和共同中心；`scripts/split-ar-layer-atlas.py` 将每个图集按固定 2×3 单元切为 24 张运行素材，部署运行只加载这些独立透明 PNG。

## AR 展示方式

扫描识别卡后自动展开六层；独立预览默认先对齐，可点“展开六层”。六张图层保持共同中心轴和相同朝向，只沿轴向前后错时弹开；轴向深度跨度约 1.03 个模型单位。独立预览采用固定斜视角，让层间距清楚可见。点“收拢六层”会将部件恢复到完全对齐。扫描卡仍是定位用图；镜头跟踪来自 MindAR，浏览器内动效是 Three.js 分层平面表现，不是任意图片自动三维重建或专家确认的文物复原。

参考用户提供的动态 AR 教程，作品使用独立纹样层、分层动画和识别触发流程。教程中的外框旋转仅作为示范；本项目按用户指定不对纹样做旋转动画，六层只沿共同中心轴展开。
