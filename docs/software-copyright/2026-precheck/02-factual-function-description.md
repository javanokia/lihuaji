# 故事语义驱动的传统纹样辅助创作 — 主要功能核对底稿

> **仅供核实，AI辅助生成。不可作为“未使用AI撰写文档或生成登记申请材料”的法定签章材料直接提交。**

实物软件入口：https://yzou6525-ai.github.io/lihuaji/#story

## 与公开源码相符的主要功能介绍

本软件面向将个人叙事转化为传统纹样构图的辅助创作场景，提供故事输入、语义要素提取、可用文化素材检索、候选方案生成、人工调整和创作过程导出的完整交互流程。使用者在页面输入不超过五百字的短故事，并可补充情绪、人物关系、使用场合和祝愿方向等条件。系统默认采用本地词表和规则提供者，对故事中出现的关键词及用户选择进行处理，形成有结构的情绪、关系、场景和设计倾向信息。随后，软件从具备来源字段并经过项目级公开资料核对的文化元素数据中筛选可使用的纹样主题，限制不明来源或未经审核状态的数据直接进入生成流程。系统依据候选纹样、构图规则与调色板，利用随机种子构造三套 SVG 形式的数字纹样方案，并为方案显示色彩与构图选择理由。使用者可以查看相关文化资料出处，选择一套候选结果，也可要求某套方案换版，并对纹样数量与组合、色谱、圆形或斜向等构图方式进行人工调整。实际点击产生的选择、调整前后差异、候选版本和时间信息会加入当前创作会话。使用者可导出选定纹样的 SVG 文件及记录创作过程的 JSON 文件，JSON 包含实际使用的规则提供者、结构化意图、资料来源、候选方案、人工操作和作品摘要校验信息。系统允许进一步将选定图案交给网站现有的数字绣稿参考和 AR 展示模块。当前公开部署默认不运行在线大语言模型，也没有自动为作品生成专属图像识别卡；创作阶段的 SHA-256 校验只用于内容一致性核查，并非作品著作权登记或区块链确权。文化资料的项目来源核对不等同于传统工艺专家认证，候选构图及寓意解释均应由用户自行审查。
