## 与公开源码相符的主要功能介绍

本软件用于展示数字化针迹数据的构成、顺序和视觉播放过程，帮助使用者观察不同针迹示意之间的运动与结构区别。系统载入由项目自编的针迹 JSON 数据文件，通过数据校验检查示例名称、针迹数量、编号顺序、分组、颜色与二维起止坐标等字段的有效性，防止异常数据直接进入播放状态。教学界面提供针迹类别选择、播放、暂停、上一针、下一针、重新开始和播放进度拖动等交互方式，并可以调整播放速度和决定是否显示针落点。画面由独立的针迹播放状态控制程序与三维绘制视图协同完成，针路会按照当前播放位置逐步出现，使用者可观察已完成针段、正在绘制的局部针段及相应点位。显示区域支持缩放、平移与适配视图，以便检查针段之间的方向和疏密关系。公开示例包含直线针、套针和滚针的项目数字演示资料，也包含一组梨花瓣散套的五十六针数字设计。散套设计按二十八、十四、十四针分批显示，可在普通逐针方式和十一秒数字显影方式之间切换。数字显影拥有独立的时间线状态，支持暂停、继续、重播、移动播放进度和退出后恢复普通练习。使用者进入相关学习路径时，软件还可以与当前浏览器中的学习进度数据相联系，但进度不会自动在不同账户或设备间同步。系统使用 Three.js 作为三维渲染依赖，项目自研部分主要承担针迹数据组织、播放器控制、动画时间线、界面交互和资源管理。所有针迹数据均为教学用数字示意，不代表专家逐针复原的苏绣历史针序，也没有针对实体线材张力、真实背面针路和工艺生产可行性完成验证。
