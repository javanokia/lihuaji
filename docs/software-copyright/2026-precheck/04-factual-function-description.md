## 与公开源码相符的主要功能介绍

本软件用于在浏览器中展示具有空间层次的传统纹样数字构图，提供三维预览、预设图像识别、增强现实跟踪、图层展开收拢和局部信息观察功能。用户打开 AR 展示入口后，可以在不授权摄像头的情况下查看预设梨花纹样数字构图，以拖动旋转观察其在不同深度上的视觉层次。页面提供赏纹、解绣和看针模式：赏纹显示完整构图，解绣加大图层间的空间距离，看针允许选择指定图层并查看与之关联的解释信息。系统为图层提供加载、显示、透明度控制、动画过渡、选中高亮与释放管理。预设的梨花构图由保持相同像素坐标的多层图像组成，交互控制会根据模式调整图层位置，形成二维图像分层后的空间视觉效果。用户也可以在明确同意后开启设备摄像头，利用预设识别卡进行图像特征检测，获得目标位置及姿态，并使数字构图跟随识别卡变化；目标短暂丢失时由项目状态控制逻辑处理平稳过渡与恢复。为了减少相机依赖，系统另提供示例图片识别验证与本地三维预览入口。对于由故事创作模块产生的符合约束的 SVG 图形，软件能校验支持的图形元素与属性，将包含语义标记的矢量组分别绘制为五张对齐位图，之后使用原有固定梨花识别卡显示用户选定图案。技术实现使用 MindAR 执行图像特征识别，Three.js 执行三维绘制，项目自研模块重点实现图层管理、动画、目标状态过渡、拾取交互和受限 SVG 分层处理。软件不提供任意上传图片直接生成实体三维模型的能力，识别效果与设备摄像头、浏览器性能、光照和识别卡质量有关。公开验证记录不能视为所有实体手机及 WebXR 设备已经通过测试。
