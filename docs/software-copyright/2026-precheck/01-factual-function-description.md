# 图像分色与数字绣稿辅助设计 — 主要功能核对底稿

> **仅供核实，AI辅助生成。不可作为“未使用AI撰写文档或生成登记申请材料”的法定签章材料直接提交。**

实物软件入口：https://yzou6525-ai.github.io/lihuaji/#create

## 与公开源码相符的主要功能介绍

本软件面向传统纹样与数字刺绣参考稿的制作场景，为用户提供浏览器端图像导入、参数设置、颜色分析、数字针路生成和设计结果导出功能。使用者可从本地选择具有使用权的 PNG、JPEG 或 WebP 图片，系统对文件类型、大小及像素尺寸进行检查，完成加载和适配处理后，在页面显示当前处理素材。使用者根据预期画面输入作品名称、参考成品边长和线距，并选择使用的颜色数量和直线针、套针或滚针示意类型。操作提交后，软件通过浏览器画布读取图像像素，根据自设的数字参考色谱进行颜色近似匹配，将图像分割与颜色信息映射为可视化图案以及分层针路参考数据。色彩处理包含 CIELAB 颜色坐标转换与相近色检索，针路数据包含数字编号、所属层级、针法类别、颜色编码和二维起止位置。系统在结果区展示当前图稿、生成的针路段数、参考颜色数量及启发式可绣性评分，并根据处理结果提示应注意的工艺限制。使用者可以将图案保存为 SVG 矢量文件，将数字针路保存为包含坐标及参考颜色信息的 CSV 文件，以便后续编辑、对照或人工试绣。照片及图像计算在当前浏览器完成，不依赖服务器上传照片或将照片存入公共仓库。软件既可处理用户自行上传的照片，也能够使用本平台已有、并标注来源与许可的纹样作为转稿参考；在相关来源存在时，导出数据可保留原作出处信息。软件生成的是数字工艺参考稿，不提供实物刺绣的针序认证、物理线张力模拟、厂商丝线色号自动匹配或工厂机器刺绣文件的完整转换功能。用户仍需结合实物材料和试绣结果判断制作可行性。
