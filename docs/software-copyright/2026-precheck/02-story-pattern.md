## 真实功能界限
- 入口：`https://yzou6525-ai.github.io/lihuaji/#story`。
- 接受不超过500字的故事及关系/情绪/场合等选择，本地词表和规则识别，结合有来源的文化条目形成候选纹样与设计解释。
- 按 seed 生成三套程序化 SVG 构图；人工选择、换版、调整纹样/色谱/构图；可下载作品 SVG、创作过程 JSON 与 SHA-256 校验记录。
- 远程模型提供的是协议接口和回退逻辑，**GitHub Pages 未部署在线大模型服务**；不称为大模型智能创作成功案例。
- 过程记录的 SHA-256 只是文件摘要，不等于版权确权或区块链登记。

## 核心文件
- `assets/intent-engine.js`：词表、规则、协议验证、回退。
- `assets/knowledge-retriever.js`：本地知识核验和限定范围检索。
- `assets/story-page.js`：故事输入、三方案生成、选择、修改、跳转、导出。
- `assets/story-session.js`：会话记录、操作日志、SVG 哈希。
- `assets/engine.js` 的 `generateMotifConcept`、`motifSVG`、`rng`、色谱与 SVG 渲染相关共享部分。
- `content/cultural-knowledge.json`、`content/sources.json` 和 `contracts/story-to-intent.schema.json` 是事实来源及接口契约，**不是全部属于原创程序的证据**。
- 测试：`scripts/story.test.cjs`、`scripts/story-acceptance.cjs`；`docs/AIGC-WORKFLOW.md` 是现有事实参考，不应冒充由人撰写的本次法定提交说明书。

## 实际操作与截图清单
1. 打开 `#story`，填入无个人信息的虚构故事，保存文本与输入截屏。
2. 完成生成后截3套候选及使用来源；保存种子与输出。
3. 选择一套，手动修改至少一项纹样与色谱并确认；保存修改前后画面。
4. 点击“换一版”并记录种子/方案差异，不声称随机输出完全不同或已通过专家评价。
5. 下载 SVG 和创作过程 JSON，检查 `usedRemoteAI` 的真实值、humanModified、sources、哈希。
6. 与数字绣稿软件分开核验：故事软件负责生成方案和过程，`#create` 的分色针路应归于另一个软件，但接口衔接需要明确。
